Canva Editing

Canva is the most popular graphic design tool online. it is a free online design platform that allows users to create social media graphics, presentations, posters, documents and other visual content. The app includes templates for users to use. The platform is free to use but also offers paid subscriptions like Canva Pro and Canva for Enterprise for additional functionality.

I used Canva to create and design my own self-care plan. I personally arranged the layout, selected the colors, and added elements to make the design visually appealing and organized.

Edge Browser

Microsoft Edge is a web browser developed by Microsoft. It is based on the Chromium engine and offers a fast, secure, and efficient browsing experience. Edge includes features like vertical tabs, integrated PDF viewer, and seamless integration with other Microsoft services.

I use Microsoft Edge as my primary web browser due to its performance and integration with the Windows operating system.

ChatGPT

ChatGPT is an AI language model developed by OpenAI. It is designed to generate human-like text based on the input it receives. ChatGPT can be used for various purposes, including answering questions, generating creative content, and assisting with tasks that require natural language understanding.

I use ChatGPT to help me with writing tasks and to get information on various topics. It also helps me to generate ideas and improve my writing skills by providing suggestions and feedback. And it also helps me fix my grammar and spelling mistakes in my writing.

Pinterest

Pinterest is a social media platform that allows users to discover, save, and share ideas through visual bookmarks called "pins." It is particularly popular for its focus on creative and DIY content, making it a valuable resource for inspiration in areas like home decor, fashion, and recipes.

I use Pinterest to find inspiration for my projects and to save ideas for future reference and also to find some photos to save and input in my projects.

Visual Studio

Visual Studio is an integrated development environment (IDE) developed by Microsoft. It is used for developing computer programs, websites, web services, mobile applications, and cloud applications.

I use Visual Studio for developing my software projects due to its powerful debugging capabilities and seamless integration with the .NET framework.
